Otella logo — round 2

Same mark, wordmark rebuilt. Five directions below, each shown at actual nav size and zoomed for inspection.

What was wrong: the old wordmark forced both text lines to the exact same pixel width using SVG textLength/lengthAdjust="spacing" — so "OTELLA" (6 letters) got stretched wide and "SPEECH + SWALLOW" (17 characters) got squeezed narrow, to make them match. That's the mangled tracking. Everything below sizes type naturally instead, and sits larger overall.
